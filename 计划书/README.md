## 文件夹用途

- **核心迭代蓝本**：`下一步改进指南.md` —— 每章「现状依据 → 问题 → 方案 → 落地步骤 → 验收 → TDD」闭环
- **历史归档**：`archive/` —— 旧版指南保留追溯，不删除
- **未来扩展**：后续可在此文件夹新增专题计划（如 `v3.3-安全纵深-详细设计.md`、`v4.0-架构拆分-切片清单.md`）

## 使用约定

1. **不动源码**：本文件夹只放计划文档，不改任何代码
2. **版本对齐**：文档基线版本必须与 `workflow_status.md` 最新一轮一致
3. **漂移修正**：发现文档与真实代码不一致时，立即修正并在「漂移修正记录」章节登记
4. **旧版归档**：重写指南时，旧版移入 `archive/`，不删除（保留追溯）
5. **每版清理**：发版后清理 `reports/` 与 `final-report-*.html` 等中间产物，保持仓库只留最新版本
